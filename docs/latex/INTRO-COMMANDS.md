# Вводная лабораторная: порядок выполнения

## Подключение к кластеру
Работа выполнена с использованием двух окон PowerShell. В первом окне установлено SSH-соединение с суперкомпьютером и выполнены серверные команды. Во втором окне выполнены локальные операции Windows и передача файлов. Ниже приведены использованные операции и соответствующие команды без символов приглашения оболочки.

### 1. Подключение к управляющему серверу.
На персональном компьютере открыто первое окно PowerShell через Win+R и команду `powershell`. Подключение выполнено следующей командой:

```
ssh -i "$env:USERPROFILE\.ssh\id_ed25519" tm3u20@login1.hpc.spbstu.ru
```

Для аутентификации использован SSH-ключ `id_ed25519`. После входа в терминале отобразилось приглашение `tm3u20@login1`. Ключ сервера был принят при первоначальном подключении.

### 2. Получение информации о сервере и очереди.
После подключения в первом окне последовательно выполнены команды:

```
hostname
whoami
sinfo
squeue -u "$USER"
```

Получены имя сервера `login1.cluster`, имя пользователя `tm3u20` и список разделов кластера. Первоначальный вывод `squeue` содержал только заголовок таблицы, то есть активных заданий не было. Состояние `idle` в выводе `sinfo` обозначало свободные узлы.

## Вводная лабораторная: узел, JSON и Python
### 3. Интерактивное выделение вычислительного узла.
В первом окне на управляющем сервере выделение ресурсов выполнено с помощью `salloc`. Команда имеет следующий вид:

```
salloc -N1 -p cascade --ntasks=1 --cpus-per-task=4 --time=00:20:00
```

После ожидания ресурсов получено сообщение `Granted job allocation`. Параметры приведённой команды задают один узел раздела `cascade`, четыре CPU и ограничение времени 20 минут. Номер задания и имя выделенного узла определены командами:

```
echo "$SLURM_JOB_ID"
scontrol show hostnames "$SLURM_JOB_NODELIST"
```

Первая команда вывела номер текущего задания, вторая - имя выделенного узла. Значения этих параметров назначаются планировщиком при каждом выделении ресурсов.

### 4. Переход на вычислительный узел.
Переход на выделенный узел выполнен по SSH. В следующем варианте команды имя узла автоматически определяется из текущего выделения Slurm:

```
ssh "$(scontrol show hostnames "$SLURM_JOB_NODELIST" | head -n 1)"
```

После перехода имя узла и учётная запись проверены командами:

```
hostname
whoami
```

При первоначальном выполнении вводной части команда `hostname` вывела `n06p049`. Таким образом подтверждён переход с управляющего сервера на вычислительный узел. Первое окно использовалось далее для работы на этом узле.

### 5. Создание локального JSON-файла.
На персональном компьютере открыто второе окно PowerShell. Локальные команды выполнены вне SSH-сеанса, при приглашении вида `PS C:\Users\Admin>`. Создание каталога и входного файла задаётся следующим блоком:

```
$introDir = Join-Path $env:USERPROFILE "Documents\spline-intro"
New-Item -ItemType Directory -Force -Path $introDir | Out-Null
Set-Location $introDir
'{"matrix": [[1, 2, 3], [4, 5, 6]]}' | Set-Content -Encoding ascii input.json
Get-Content .\input.json
```

Блок создаёт рабочий каталог `Documents\spline-intro`, записывает матрицу в `input.json` и выводит содержимое файла. Исходный JSON сформирован на персональном компьютере.

### 6. Передача входного файла через SCP.
Передача файла выполнена во втором, локальном окне из каталога с `input.json`:

```
scp -i "$env:USERPROFILE\.ssh\id_ed25519" .\input.json tm3u20@login1.hpc.spbstu.ru:~/input.json
```

После завершения передачи содержимое файла проверено в первом окне на вычислительном узле:

```
cat ~/input.json
```

Домашний каталог доступен с управляющего и вычислительного узлов. На вычислительном узле прочитана переданная матрица `[[1, 2, 3], [4, 5, 6]]`.

### 7. Создание Python-скрипта.
В первом окне на вычислительном узле подключён модуль Python:

```
module load python/3.10
```

Создан скрипт `transpose.py`. Полный блок создания файла приведён ниже; строка `PY` завершает многострочный ввод:

```
cat > ~/transpose.py <<'PY'
import json
from pathlib import Path

source = Path.home() / "input.json"
target = Path.home() / "output.json"
data = json.loads(source.read_text(encoding="utf-8"))
matrix = data["matrix"]
assert matrix and matrix[0], "Empty matrix"
assert all(len(row) == len(matrix[0]) for row in matrix), "Ragged matrix"
result = {"matrix": [list(row) for row in zip(*matrix)]}
target.write_text(json.dumps(result, indent=2), encoding="utf-8")
print("Saved:", target)
PY
```

Скрипт читает JSON, проверяет непустоту и прямоугольность матрицы, транспонирует её и записывает результат. Использованы стандартные библиотеки Python `json` и `pathlib`; внешние зависимости для вводной части не потребовались.

### 8. Преобразование матрицы и запись результата.
В первом окне на вычислительном узле выполнены запуск скрипта и просмотр выходного файла:

```
python3 ~/transpose.py
cat ~/output.json
```

Скрипт вывел путь к сохранённому файлу. Команда `cat` показала JSON с транспонированной матрицей:
Матрица [[1,2,3],[4,5,6]] преобразована в [[1,4],[2,5],[3,6]].

### 9. Передача результата на персональный компьютер.
В локальном окне PowerShell из каталога `Documents\spline-intro` выполнены скачивание и просмотр результата:

```
scp -i "$env:USERPROFILE\.ssh\id_ed25519" tm3u20@login1.hpc.spbstu.ru:~/output.json .\output.json
Get-Content .\output.json
```

Результат получен на персональном компьютере. В выходном файле сохранены строки матрицы `[1, 4]`, `[2, 5]`, `[3, 6]`.

### 10. Завершение работы и освобождение ресурсов.
SSH-сеанс вычислительного узла завершён в первом окне командой:

```
exit
```

После возвращения на `login1` выделение освобождено и выполнена проверка очереди. Для текущего задания используются команды:

```
scancel "$SLURM_JOB_ID"
squeue -u "$USER"
```

Переменная `SLURM_JOB_ID` содержит номер задания в оболочке `salloc`. После освобождения ресурсов соответствующее задание исчезло из активной очереди. При истечении лимита времени ресурсы освобождаются планировщиком автоматически.

В результате выполнены подключение по SSH, получение информации о кластере и очереди, выделение узла, передача входного JSON, обработка матрицы Python-скриптом, получение `output.json` на персональном компьютере и освобождение ресурсов.

Первоначально вводная часть выполнена в задании 9261607 на `n06p049`. В приведённых командах используются параметры текущего выделения Slurm, поэтому имя вычислительного узла не зафиксировано в командах подключения.
